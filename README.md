# Certificación Laboral — Alliance Network E.I.R.L.

Certificado laboral con diseño corporativo (formato A4, una página).

## Archivos

| Archivo | Descripción |
|---|---|
| `certificado-laboral.html` | Versión **editable**: ábrela en cualquier navegador, haz clic sobre cualquier texto para modificarlo y pulsa **«Descargar PDF»** (o `Ctrl+P` → Guardar como PDF). |
| `certificado-laboral.pdf` | Versión **final lista**, con el bloque de firma incluido. |

## Cómo editar

1. Abre `certificado-laboral.html` en Chrome, Edge o cualquier navegador.
2. Haz clic sobre el texto que quieras cambiar (nombre, fecha, salario, funciones, etc.) y escribe directamente.
3. Pulsa el botón **Descargar PDF** de la barra superior y elige «Guardar como PDF» con márgenes en «Ninguno».

La barra de ayuda superior no aparece en el PDF impreso.
